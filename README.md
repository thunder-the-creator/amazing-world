# Маленький мир · фундамент сказочной планеты

База мобильной браузерной 3D-игры на **Vite + TypeScript + чистом Three.js**.
Серая планета с мягкими холмами, горным массивом, спящим озером и каменными
акцентами под мягкой облачной вуалью, почти чёрное звёздное небо,
вращение пальцем или мышью, лёгкая инерция и локальное пробуждение поверхности
от короткого тапа. Вслед за волной прорастают трава, нежно-розовые и лавандовые цветы.
Без React, загружаемых текстур, внешних шрифтов, постобработки и сюжета.

## Запуск на Windows 10

1. Установите **Node.js 22 LTS (22.12 или новее)** с npm. Откройте новый PowerShell.
2. Перейдите в папку проекта:

   ```powershell
   cd C:\Projects\amazing-world
   npm ci
   npm run dev
   ```

3. Откройте адрес `Local`, который напечатает Vite (обычно `http://localhost:5173`).
   Остановка сервера: `Ctrl+C`. Если PowerShell блокирует `npm.ps1`, используйте
   `npm.cmd ci` и `npm.cmd run dev`.

Для проверки на POCO M5 / Vivo V25 5G подключите телефон и ноутбук к одной
Wi-Fi-сети. Откройте на телефоне адрес `Network`, напечатанный Vite, например
`http://192.168.1.10:5173`. Если Windows запросит доступ для Node.js, разрешите
его для частной сети. Используйте актуальный Chrome с WebGL 2.

Проверка TypeScript и production-сборка:

```powershell
npm run build
npm run preview
```

Результат сборки — папка `dist`. Для повторной установки используйте `npm ci`:
версии зависимостей зафиксированы в `package-lock.json`.

## Управление и продолжение разработки

- Свайп вращает планету; после отпускания скорость плавно затухает.
- Короткий тап: до 280 мс, отклонение не более 9 CSS-пикселей. Долгое нажатие,
  свайп, отменённое касание и несколько пальцев не вызывают тап.
- Мышь работает аналогично. При фокусе на планете доступны стрелки клавиатуры.
- Колесо мыши и pinch двумя пальцами плавно приближают/отдаляют камеру.
- При `prefers-reduced-motion: reduce` инерция и автовращение отключены.
- Тап по поверхности создаёт DOM-событие `planet-tap` с координатой в локальном
  пространстве планеты и запускает волну пробуждения. Тап по фону ничего не создаёт.

```ts
import type { PlanetTapDetail } from './main';

document.querySelector('canvas')!.addEventListener('planet-tap', (event) => {
  const { point } = (event as CustomEvent<PlanetTapDetail>).detail;
  console.log(point); // { x, y, z } на поверхности, до поворота планеты
});
```

## Пробуждение поверхности

Волна расширяется по сфере в течение **1.9 секунды** с мягким стартом,
плавным ускорением и торможением (smoothstep / ease-in-out).
Внутри области холодный серый сменяется мягким природным зелёным (`0x638f60`);
на освещённых участках примешивается тёплый золотистый (`0xb3a66b`, до 35%).
За пределами волны сохраняется исходный материал. Области плавно объединяются.

Маска рассчитывается для каждого пикселя во fragment shader единственной сферы
96×64. Vertex shader передаёт только нормализованное локальное направление;
после интерполяции оно повторно нормализуется один раз на пиксель. Границы
формируются через dot product и smoothstep, а `fwidth` обеспечивает минимальную
ширину мягкого края в один пиксель даже при сниженном разрешении рендеринга.
Цикл обрабатывает только сохранённые точки (до 16), без `acos`, вычисления
длины на каждую область, текстур маски, дополнительных Mesh и проходов рендеринга.
Стандартное освещение Three.js сохранено. Вращение не сдвигает пробуждённые места.

Отладочный лимит — **16 областей** (радиус каждой — 0.52 радиана). После лимита
новые тапы игнорируются, прежние области не исчезают. Состояние хранится в памяти
страницы и сбрасывается при перезагрузке. Во время скрытия вкладки волны приостановлены.
Параметры находятся в начале `src/awakening.ts`.

## Спящий ландшафт · Stage 4A

Композиция состоит из одного низкого связного хребта с плавными седловинами
и склонами, одного озера неправильной формы и 12 камней разных размеров.
В Stage 5A высота хребта уменьшена до ≈0.096 радиуса планеты над базовым
рельефом, камни уменьшены до 65% прежнего масштаба.
Шесть небольших камней отмечают берег; остальные образуют отдельные скальные
акценты, оставляя большую часть поверхности открытой. Цвета гор холодные серые,
камней — приглушённые, воды — мутные серо-оливковые. Вода неподвижна и непрозрачна,
без отражений, текстур, анимации и дополнительных проходов рендеринга.

Основная сфера сохраняет сетку 96×64; локальное уточнение добавлено только
вокруг озера. Берег заменяет вырезанный участок сферы и стыкуется с его границей.
Это исключает пересечение воды с грубой сеткой исходной планеты. Горы и берег
объединены в одну геометрию; 12 камней используют одну геометрию, общий с горами
материал и один `InstancedMesh`. Весь ландшафт вращается вместе с планетой.

Тап выбирает ближайшую поверхность земли, гор, воды или камней. Событие
`planet-tap` по-прежнему передаёт координату в локальном пространстве планеты.
Для посадки используются реальные треугольники суши, с проверкой нормали:
растения не появляются в озере, на каменистом берегу, горном массиве, внутри
валунов или на склонах круче 40°. Свободные пологие участки продолжают оживать.

В Stage 4A горы, берег, камни и озеро **остаются спящими после тапа**.
Для будущего пробуждения ландшафта доступны локальные описания `regions`, отдельный материал воды,
центры инстансов камней и атрибут `landscapeRegion` (0 — горы, 1 — берег,
2 — вода). Геометрии гор и озера уже заданы в координатах планеты; для камней
будущий шейдер должен учитывать `instanceMatrix`. Очистка озера и пробуждение
гор сейчас не реализованы; существующий awakening shader не изменён.

## Облачная вуаль · Stage 4B

Вместо отдельных облачных пятен планету укрывает **замкнутая облачная оболочка**.
На стартовой и средней дистанции она непрозрачна: горы, озеро и поверхность
скрыты, включая тёмные складки облаков. Оболочка — правильная сфера
радиуса 1.18, без расширения над горами. Пониженный рельеф целиком помещается
внутри неё. Силуэт остаётся круглым при любом повороте.

Бесшовный облачный рисунок 512×256 (один канал, 128 КБ до mipmaps) генерируется
один раз на CPU. Один texture fetch и экранные производные придают складкам
мягкое освещение; процедурного шума и ray marching во fragment shader нет.
Точные радиальные нормали сферы сохраняют гладкое освещение у полюсов и стыка UV.

Раскрытие происходит только в ближней части zoom: между 85% и 60% исходной
дистанции кадрирования. Используется **фактическая** дистанция камеры,
smoothstep и экспоненциальное сглаживание. На максимальном приближении облака
полностью исчезают, открывая серый мир; при отдалении возвращаются. Порог
нормирован на кадрирование экрана, а не задан фиксированной мировой дистанцией.

Вторая сферическая оболочка, на 2.5% больше облачной, создаёт голубовато-белый атмосферный
ореол. Прозрачность зависит от угла взгляда к нормали (Fresnel/rim), с мягким
спадом на внешнем крае. Она рисуется перед облаками, чтобы не окрашивать весь
покров. При приближении атмосфера также ослабевает. Обе оболочки односторонние,
без записи глубины, bloom, отражений и дополнительных проходов рендеринга.

Облака и ореол не участвуют в raycasting: тап проходит к существующей поверхности.
Оболочка не меняет shader пробуждения и не перехватывает жесты управления.
Очистка озера и пробуждение гор остаются задачей будущих этапов.

## Планировка и масштаб · Stage 5A

Радиус земли остаётся **1**. Высоты мягких холмов уменьшены, а внутри будущих
полян рельеф плавно выравнивается без круглых платформ и резких границ.
Базовая сетка 96×64 и локальные сетки озера/хребта не увеличены.

`src/world.ts` содержит только общие размеры и восемь ориентиров в локальном
пространстве планеты. `direction` — единичное направление, `angularRadius` —
угловой радиус в радианах, `maxSlopeDegrees` — ориентир допустимого уклона,
`leveling` — степень мягкого выравнивания. Между границами зон есть промежутки;
перед реальной установкой объекта всё равно нужно проверить поверхность raycast.

| Регион | Радиус зоны, рад | Предназначение |
| --- | --- | --- |
| Жилая поляна | 0.32 | Место для 3–5 домов и дорожек |
| Лесной сектор | 0.40 | Пространство для множества небольших деревьев |
| Поляна особенного дерева | 0.27 | Отдельный спокойный центр композиции |
| Озёрная территория | 0.43 | Существующее озеро и берег |
| Горный регион | 0.48 | Невысокий связный хребет |
| Цветочная долина | 0.30 | Пологие открытые участки |
| Тайная поляна | 0.25 | Уединённая локация на другой стороне |
| Природный резерв | 0.38 | Свободная территория для дальнейшего развития |

Ориентиры высоты **будущих** объектов: дом 0.06–0.085, обычное дерево 0.07–0.11,
особенное дерево 0.14. Это справочные размеры, объекты не создаются. Второе озеро,
лес, дома и дорожки в этом этапе не добавлены.

## Первые растения

Каждая принятая точка пробуждения создаёт до **6 пучков травы и 2 цветков**.
Трава размещается двумя небольшими группами по три пучка с открытым пространством
между ними. Занятые участки получают меньше травы вместо уплотнения посадки.
Каждый пучок начинает расти через 0.3–0.5 секунды после прихода зелёной части
волны к его позиции. Цветы появляются позже начала роста травы, с отдельными
задержками. Плавный рост через sine ease-out занимает 0.7–1.1 секунды без bounce.
Для каждого растения хранятся момент начала и конечный масштаб.

В Stage 5A масштаб пучков уменьшен до 40% прежнего, цветов — примерно до 42%,
чтобы будущие деревья и здания не конкурировали с крупной травой.
Пучок состоит из трёх коротких тонких объёмных травинок с гладкими нормалями и
округлым профилем. Центральная травинка чуть выше двух боковых. Разброс масштаба,
наклона и оттенков зелёного небольшой; пучки в группе ориентированы согласованно.
Цветы представлены двумя формами: розовый пятилистник и
маленькая лавандовая чашечка из четырёх лепестков с кремовой серединкой.

Растения размещаются на реальных треугольниках рельефа и ориентируются по
интерполированной нормали. Три `InstancedMesh` являются дочерними объектами
планеты, поэтому при вращении растения остаются на поверхности. Листья и
лепестки — маленькие объёмные округлые формы без текстур и отдельных теней.

Между основаниями сохраняется минимальное расстояние, включая соседние
пробуждённые области. Повторные тапы в плотном участке могут дать меньше растений.
Предел — **144 пучка травы и 48 цветков** (по 24 каждого типа) на сцену.
Не требуется заполнять лимиты: один тап добавляет лишь небольшую группу.
Заполнение этих лимитов не
блокирует волну пробуждения; её прежний отдельный лимит — 16 областей.
После роста матрицы инстансов больше не обновляются. Верхушки травы едва заметно
покачиваются в вершинном шейдере: цикл около 8 секунд, разная фаза у каждого
пучка, максимальное отклонение около 0.0009 радиуса планеты. Основания неподвижны;
нормали корректируются вместе с изгибом. Для ветра обновляется только один uniform
времени, без дополнительных draw call, текстур и проходов рендеринга.
При `prefers-reduced-motion: reduce` ветер приостанавливается. Цветы не качаются.
При скрытии вкладки ветер и рост
приостанавливается, после перезагрузки растения сбрасываются вместе с областями.

Быстрая проверка: тапните по серой поверхности, дождитесь роста, поверните
планету и тапните рядом с первой областью. Трава и цветы должны сохранять
положение, появляться после окрашивания земли и не скапливаться друг в друге.

## Камера и звёздное небо

Начальное кадрирование учитывает **внешний радиус атмосферы** и касательные к
сфере в перспективе. На узкой сцене используется горизонтальный угол обзора
и 96% её ширины; на широкой — вертикальный угол и 94% высоты. Планета вместе
с ореолом помещается в canvas. На компьютере уменьшены отступы существующего
текста и расширена доступная сцена: это увеличивает планету без перекрытия UI.
Фиксированного размера планеты в пикселях нет.

Pinch и колесо меняют только `targetDistance`; фактическая дистанция следует
через экспоненциальную интерполяцию с delta time. Ближний предел — **1.5 радиуса**,
что оставляет запас перед облаками, рельефом и near plane 0.1. Это позволяет
изучать мелкую растительность значительно ближе, чем прежний предел 2.2.
Дальний предел — 1.5 диапазона между ближним пределом и исходным кадрированием:
вся планета остаётся видна. Чувствительность вращения снижается вплоть до 12%.

Масштаб хранится как положение в доступном диапазоне дистанций. При смене
ориентации пересчитывается кадрирование, но сохраняется выбранное приближение;
ближний предел остаётся тем же на телефоне и компьютере. Фактическая дистанция
не меняется скачком. Пороги облаков 85–60% кадрирования достижимы на обоих типах
экранов: вблизи вуаль полностью растворяется, при отдалении возвращается.

После pinch оставшийся палец не вращает планету и не создаёт тап: нужно
отпустить все пальцы и начать новый жест. Третий палец временно приостанавливает
pinch; колесо поддерживает пиксельные, строчные и постраничные события.

Через 2.5 секунды без взаимодействия, после затухания инерции, плавно
возобновляется горизонтальное автовращение (0.025 рад/с, оборот примерно за
4 минуты). Касание, движение мыши над сценой, колесо и стрелки сразу его
останавливают. Во время удержания пальца автовращение не включается.
Скорость вращения и её плавное восстановление не зависят от FPS.

Звёздный фон — один `THREE.Points`, 400 точек на далёкой сферической оболочке.
Оболочка следует за камерой, поэтому zoom не приближает звёзды. Размеры точек
0.65–1.6 CSS-пикселя с учётом разрешения рендера; ярких звёзд немного.
Мягкий круглый профиль формируется простым шейдером без текстуры, bloom,
мерцания или отдельного render pass. Глубину фона поддерживает тёмный CSS-градиент.

## Файлы

- `src/world.ts` — единый масштаб, безопасные границы и восемь будущих регионов.
- `src/main.ts` — сцена, освещение, камера, цикл рендеринга и raycast тапа.
- `src/planet.ts` — сфера (~13.6 тысячи треугольников), локальная сетка озера и гладкие нормали.
- `src/terrain.ts` — единые определения высот, озёрной чаши и горного массива.
- `src/landscape.ts` — горы, берег, вода, инстансы камней и ограничения посадки.
- `src/clouds.ts` — замкнутый облачный покров, атмосферная оболочка и раскрытие при zoom.
- `src/awakening.ts` — GPU-маска, цвет и анимация локальных волн.
- `src/vegetation.ts` — три инстансные группы растений, размещение и каскадный рост.
- `src/controls.ts` — Pointer Events, распознавание жестов и инерция.
- `src/camera.ts` — плавный zoom, границы дистанции и сохранение масштаба.
- `src/starfield.ts` — один лёгкий Points с разными размерами и яркостью звёзд.
- `src/quality.ts` — адаптивное разрешение.
- `src/style.css` — фон, портретная/альбомная компоновка, безопасные отступы экрана.

## Производительность

Цикл ограничен 30 кадрами в секунду. DPR ограничен 1.5, буфер — примерно
900 тысячами пикселей. Раз в 2 секунды оценивается средний интервал кадров:
при интервале более 40 мс разрешение снижается; после трёх стабильных окон
менее 35 мс постепенно восстанавливается. CSS-размеры и чувствительность
управления при этом не меняются. В скрытой вкладке рендеринг приостанавливается.

Планета, ландшафт, три группы растений, звёзды и атмосфера — максимум **10 draw call**,
192 инстанса растений, 12 камней, 400 точек и около **92 тысяч треугольников**
при полном заполнении. Ландшафт строится один раз; дополнительных вычислений
для него в цикле рендеринга нет. Оболочки делят одну сетку 64×48: вместе
они добавляют 12 032 треугольника и два draw call. Каждый кадр обновляются только
два значения прозрачности; полностью растворившиеся облака не отрисовываются.
Без volumetric clouds, bloom и дополнительных проходов рендеринга.
Без теней и загрузки ресурсов.
Raycast для посадки выполняется только при тапе; шейдер пробуждения не изменён.
