# Маленький мир · первые растения

База мобильной браузерной 3D-игры на **Vite + TypeScript + чистом Three.js**.
Серая планета с мягким процедурным рельефом, холодный серо-голубой фон,
вращение пальцем или мышью, лёгкая инерция и локальное пробуждение поверхности
от короткого тапа. Вслед за волной прорастают трава и небольшие кремовые цветы.
Без React, текстур, внешних шрифтов, постобработки и сюжета.

## Запуск на Windows 10

1. Установите **Node.js 22 LTS (22.12 или новее)** с npm. Откройте новый PowerShell.
2. Перейдите в папку проекта:

   ```powershell
   cd C:\Projects\amazing-world
   npm ci
   npm run dev
   ```

3. Откройте адрес `Local`, который напечатает Vite (обычно `http://localhost:5173`).
   Остановка сервера: `Ctrl+C`. Если PowerShell блокирует `npm.ps1`, используйте
   `npm.cmd ci` и `npm.cmd run dev`.

Для проверки на POCO M5 / Vivo V25 5G подключите телефон и ноутбук к одной
Wi-Fi-сети. Откройте на телефоне адрес `Network`, напечатанный Vite, например
`http://192.168.1.10:5173`. Если Windows запросит доступ для Node.js, разрешите
его для частной сети. Используйте актуальный Chrome с WebGL 2.

Проверка TypeScript и production-сборка:

```powershell
npm run build
npm run preview
```

Результат сборки — папка `dist`. Для повторной установки используйте `npm ci`:
версии зависимостей зафиксированы в `package-lock.json`.

## Управление и продолжение разработки

- Свайп вращает планету; после отпускания скорость плавно затухает.
- Короткий тап: до 280 мс, отклонение не более 9 CSS-пикселей. Долгое нажатие,
  свайп, отменённое касание и несколько пальцев не вызывают тап.
- Мышь работает аналогично. При фокусе на планете доступны стрелки клавиатуры.
- При `prefers-reduced-motion: reduce` инерция отключена.
- Тап по поверхности создаёт DOM-событие `planet-tap` с координатой в локальном
  пространстве планеты и запускает волну пробуждения. Тап по фону ничего не создаёт.

```ts
import type { PlanetTapDetail } from './main';

document.querySelector('canvas')!.addEventListener('planet-tap', (event) => {
  const { point } = (event as CustomEvent<PlanetTapDetail>).detail;
  console.log(point); // { x, y, z } на поверхности, до поворота планеты
});
```

## Пробуждение поверхности

Волна расширяется по сфере в течение **1.9 секунды** с мягким стартом,
плавным ускорением и торможением (smoothstep / ease-in-out).
Внутри области холодный серый сменяется мягким природным зелёным (`0x638f60`);
на освещённых участках примешивается тёплый золотистый (`0xb3a66b`, до 35%).
За пределами волны сохраняется исходный материал. Области плавно объединяются.

Маска рассчитывается для каждого пикселя во fragment shader единственной сферы
96×64. Vertex shader передаёт только нормализованное локальное направление;
после интерполяции оно повторно нормализуется один раз на пиксель. Границы
формируются через dot product и smoothstep, а `fwidth` обеспечивает минимальную
ширину мягкого края в один пиксель даже при сниженном разрешении рендеринга.
Цикл обрабатывает только сохранённые точки (до 16), без `acos`, вычисления
длины на каждую область, текстур маски, дополнительных Mesh и проходов рендеринга.
Стандартное освещение Three.js сохранено. Вращение не сдвигает пробуждённые места.

Отладочный лимит — **16 областей** (радиус каждой — 0.52 радиана). После лимита
новые тапы игнорируются, прежние области не исчезают. Состояние хранится в памяти
страницы и сбрасывается при перезагрузке. Во время скрытия вкладки волны приостановлены.
Параметры находятся в начале `src/awakening.ts`.

## Первые растения

Каждая принятая точка пробуждения создаёт до **12 пучков травы и 2 цветков**.
Первый пучок начинает расти через 0.45–0.51 секунды, остальные — позже,
после прихода зелёной части волны к их позиции. Плавный рост через smoothstep
занимает 0.7–0.9 секунды. Масштаб и поворот немного различаются.

Растения размещаются на реальных треугольниках рельефа и ориентируются по
интерполированной нормали. Два `InstancedMesh` являются дочерними объектами
планеты, поэтому при вращении растения остаются на поверхности. Листья и
лепестки — маленькие объёмные округлые формы без текстур и отдельных теней.

Между основаниями сохраняется минимальное расстояние, включая соседние
пробуждённые области. Повторные тапы в плотном участке могут дать меньше растений.
Предел — **144 пучка травы и 32 цветка** на сцену. Заполнение этих лимитов не
блокирует волну пробуждения; её прежний отдельный лимит — 16 областей.
После роста матрицы инстансов больше не обновляются. При скрытии вкладки рост
приостанавливается, после перезагрузки растения сбрасываются вместе с областями.

Быстрая проверка: тапните по серой поверхности, дождитесь роста, поверните
планету и тапните рядом с первой областью. Трава и цветы должны сохранять
положение, появляться после окрашивания земли и не скапливаться друг в друге.

## Файлы

- `src/main.ts` — сцена, освещение, камера, цикл рендеринга и raycast тапа.
- `src/planet.ts` — одна сфера (~12 тысяч треугольников) с рельефом и гладкими нормалями.
- `src/awakening.ts` — GPU-маска, цвет и анимация локальных волн.
- `src/vegetation.ts` — две инстансные группы растений, размещение и рост.
- `src/controls.ts` — Pointer Events, распознавание жестов и инерция.
- `src/quality.ts` — адаптивное разрешение.
- `src/style.css` — фон, портретная/альбомная компоновка, безопасные отступы экрана.

## Производительность

Цикл ограничен 30 кадрами в секунду. DPR ограничен 1.5, буфер — примерно
900 тысячами пикселей. Раз в 2 секунды оценивается средний интервал кадров:
при интервале более 40 мс разрешение снижается; после трёх стабильных окон
менее 35 мс постепенно восстанавливается. CSS-размеры и чувствительность
управления при этом не меняются. В скрытой вкладке рендеринг приостанавливается.

Планета и две группы растений — максимум **3 draw call**, 176 инстансов растений
и около 48 тысяч треугольников при полном заполнении. Без теней и загрузки ресурсов.
Raycast для посадки выполняется только при тапе; шейдер пробуждения не изменён.
Зависимость времени
затухания от FPS устранена. Целевые 30 FPS на POCO M5 требуют проверки на самом
телефоне; браузерная эмуляция не измеряет производительность его GPU.

Vite может предупредить о размере JS-чанка: основную часть составляет Three.js
(весь JS около 139 КБ gzip). Это предупреждение не мешает сборке.
